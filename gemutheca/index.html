ゲムテカ プライバシーポリシー

最終更新日: 2026年8月3日

収集する情報

ゲムテカは、利用者の個人情報を収集しません。

アプリに登録したゲームのタイトル、プレイ状態、評価、メモなどは、すべて利用者の端末の中にのみ保存されます。開発者を含む第三者がこれらを閲覧することはできません。

アカウント登録はありません。氏名・メールアドレス・電話番号・位置情報・連絡先・写真などを求めることはありません。

現在、広告は表示していません。利用状況の分析（アナリティクス）やクラッシュレポートの外部送信も行いません。

外部との通信

ゲームを検索したときに限り、ゲーム情報データベース IGDB（Twitch 社）へ検索語を送信します。送信されるのは利用者が入力した検索語だけで、登録済みのゲーム・メモ・評価が送られることはありません。

検索結果のカバー画像は、IGDB の画像配信サーバーから読み込まれます。画像は端末内に一時保存（キャッシュ）されます。

  • 通信先: api.igdb.com / id.twitch.tv / images.igdb.com
  • IGDB のプライバシーポリシー: https://www.twitch.tv/p/legal/privacy-notice/

検索を行わなければ、アプリは外部と通信しません。手動でゲームを登録する場合、通信は一切発生しません。

データの保存とバックアップ

データは端末内のデータベースに保存されます。アプリを削除するとデータも削除されます。

設定画面から、すべてのデータを JSON ファイルとして書き出せます。書き出したファイルの保存先は利用者が選び、その後の取り扱いは利用者の管理下に置かれます。開発者はこのファイルを受け取りません。

端末の OS が提供するバックアップ機能（iCloud バックアップ / Google の自動バックアップ）の対象になる場合があります。その取り扱いは各 OS 提供者のプライバシーポリシーに従います。

子どものプライバシー

本アプリは特定の年齢層を対象としていませんが、個人情報を収集しないため、年齢にかかわらず追加の情報が収集されることはありません。

第三者提供

収集していないため、第三者へ提供する情報はありません。

ポリシーの変更

内容を変更する場合は、本ページの最終更新日を改めます。重要な変更がある場合はアプリ内でお知らせします。
